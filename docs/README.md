# docs/

This directory holds one generated file. The documentation itself moved.

| What | Where |
|---|---|
| Operator and embedder documentation, authored | `apps/docs/content/docs/` |
| The same, rendered | https://deskbell.dev/docs |
| Widget option reference, generated | `widget-customization.md` (this directory) |

`widget-customization.md` stays here because it is generated by
`scripts/gen-widget-docs.ts` from the descriptor in `packages/shared`, and CI
byte-compares it (`pnpm docs:widget --check`). It exists for people reading a
checkout rather than the site. Do not edit it; run `pnpm docs:widget` after
changing the descriptor.

The site renders the same tables directly from that descriptor, so the two
cannot disagree.

Everything else lives in `apps/docs`. A documentation change belongs in the same
pull request as the code it describes, which is why the content sits in this
repository rather than its own.

`.ai/` is the other half of the split: `docs/` is for people **running**
Deskbell, `.ai/` is for people **building** it.
